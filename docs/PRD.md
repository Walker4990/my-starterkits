# 견적서 웹 뷰어 MVP PRD

## 🎯 핵심 정보

**목적**: 프리랜서가 Notion에 입력한 견적서를 클라이언트가 링크 하나로 웹에서 보고 PDF로 받게 한다.
**사용자**: Notion으로 견적을 관리하는 1인 개발자/프리랜서(입력)와 계정 없이 열람하려는 비개발자 클라이언트(열람).

## 🚶 사용자 여정

```
[관리자] Notion에 견적 입력 → 공유 링크 전달
   ↓
[클라이언트] 공유 링크 클릭
   ↓
1. 링크 확인 (토큰 검증 → Notion 조회)

   [유효] ────────────→ 견적서 조회 페이지
   [만료] ────────────→ 만료 안내 페이지
   [없음/비공개] ─────→ 찾을 수 없음 페이지
   [Notion 장애] ─────→ 오류 안내 페이지
   ↓
2. 견적서 조회 페이지
   ↓ [PDF 다운로드 클릭]
3. PDF 파일 저장 → 같은 페이지 유지
   ↓ [Notion에서 견적 수정 후 재접속, 최대 1분 뒤 반영]
4. 갱신된 견적서 조회 페이지
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 견적서 조회 | 공유 토큰으로 Notion 견적서를 조회해 헤더·품목표·비고 표시 (Notion 수정은 최대 1분 뒤 반영) | 제품의 핵심 가치 | 견적서 조회 페이지 |
| **F002** | 금액 계산 | 공급가액·세액·합계를 계산해 웹/PDF에 동일하게 표시 | 견적서의 핵심 정보 | 견적서 조회 페이지 |
| **F003** | PDF 다운로드 | 한글이 깨지지 않는 A4 PDF를 파일로 내려받기 | 클라이언트 보관·결재 용도 | 견적서 조회 페이지 |
| **F004** | 링크 상태 처리 | 유효기간 당일(KST 00:00)부터 만료로 보고, 만료와 공개 아님·없는 링크를 구분해 안내 | 오래된 견적 노출 차단 | 만료 안내 페이지, 찾을 수 없음 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F005** | 장애 안내 | Notion 조회 실패 시 안내와 `requestId` 표시 | 실패 원인 추적 | 오류 안내 페이지 |
| **F006** | 반응형 열람 | 모바일 화면 폭에서 품목표를 가로 스크롤 없이 열람 | 클라이언트 모바일 사용 | 견적서 조회 페이지 |

> 인증: 클라이언트는 로그인 없이 열람하므로 회원가입/로그인 기능을 두지 않는다. (기존 스타터킷 인증은 MVP에서 사용하지 않음)

### 3. MVP 이후 기능 (제외)

- 관리자 화면(견적 작성/수정 UI)
- 견적 수락·거절·수정 요청, 전자서명, 결제
- 로고·사업자 정보·입금 계좌 브랜딩
- 접근 통계, 다국어·다중 통화, 템플릿 커스터마이징

## 📄 페이지별 상세 기능

### 견적서 조회 페이지

> **구현 기능:** `F001`, `F002`, `F003`, `F006` | **메뉴 위치:** 공유 링크 진입 > 견적서 조회

| 항목 | 내용 |
|------|------|
| **역할** | 유효한 견적서 한 건을 보여 주고 PDF를 제공하는 핵심 페이지 |
| **진입 경로** | 유효한 공유 링크 클릭 |
| **사용자 행동** | 견적 내용과 금액을 확인하고, PDF를 내려받는다 |
| **주요 기능** | • 견적번호·클라이언트명·발행일·유효기간 헤더 표시<br>• 품목표(품명·수량·단가·금액) 표시<br>• 공급가액·세액·합계 표시<br>• 비고 표시<br>• 품목이 없으면 안내 문구 표시, PDF 버튼 비활성<br>• 모바일에서 표가 가로 스크롤 없이 읽힘<br>• **PDF 다운로드** 버튼 (파일명 `견적서_{견적번호}_{클라이언트명}.pdf`) |
| **다음 이동** | PDF 다운로드 → 같은 페이지 유지, 조회 실패 → 오류 안내 페이지 |

---

### 만료 안내 페이지

> **구현 기능:** `F004` | **메뉴 위치:** 공유 링크 진입 > 만료 안내

| 항목 | 내용 |
|------|------|
| **역할** | 유효기간이 지난 링크임을 알리는 안내 |
| **진입 경로** | 유효기간이 지난 견적서의 공유 링크 클릭 (자동 전환) |
| **사용자 행동** | 만료 사실을 확인하고 발행자에게 재요청한다 |
| **주요 기능** | • 만료 안내 문구 표시<br>• 견적 내용은 표시하지 않음 |
| **다음 이동** | 없음 (종료) |

---

### 찾을 수 없음 페이지

> **구현 기능:** `F004` | **메뉴 위치:** 공유 링크 진입 > 찾을 수 없음

| 항목 | 내용 |
|------|------|
| **역할** | 없는 링크와 공개 상태가 아닌 링크를 동일하게 안내 |
| **진입 경로** | 존재하지 않거나 공개 상태가 아닌(작성중·비공개) 견적서의 링크 클릭, 잘못된 형식의 링크 (자동 전환) |
| **사용자 행동** | 링크를 다시 확인하거나 발행자에게 문의한다 |
| **주요 기능** | • "찾을 수 없습니다" 안내 문구 표시<br>• 없음·작성중·비공개를 구분하지 않는 동일한 화면 |
| **다음 이동** | 없음 (종료) |

---

### 오류 안내 페이지

> **구현 기능:** `F005` | **메뉴 위치:** 공유 링크 진입 > 오류 안내

| 항목 | 내용 |
|------|------|
| **역할** | Notion 조회 실패 시 사용자에게 상황을 알리고 추적 단서를 제공 |
| **진입 경로** | Notion 호출 실패(재시도 후에도 실패)로 자동 전환 |
| **사용자 행동** | 오류를 확인하고 `requestId`를 발행자에게 전달하거나 재시도한다 |
| **주요 기능** | • 오류 안내 문구 표시<br>• `requestId` 표시<br>• 다시 시도 버튼 |
| **다음 이동** | 다시 시도 → 링크 상태에 따라 견적서 조회, 만료 안내, 찾을 수 없음 페이지 중 하나 |

## 🗄️ 데이터 모델

### 견적서 (Quote, Notion 데이터 소스)
- 견적번호, 클라이언트명, 발행일, 유효기간, 세율, 상태, 공유 토큰, 비고
- 품목 → 견적 품목 (관계)

### 견적 품목 (QuoteItem, Notion 데이터 소스)
- 품명, 수량, 단가, 순서
- 견적 → 견적서 (관계)

> 속성별 Notion 타입, 조회 방식은 `docs/NOTION_API_GUIDE.md` 참고.

## 🛠️ 기술 스택 (최신 버전)

### 🎨 프론트엔드 프레임워크
- **Next.js 16** (App Router, Server Component) - 견적서 서버 렌더링
- **TypeScript 5** - 타입 안전성
- **React 19** - UI 라이브러리

### 🎨 스타일링 & UI
- **Tailwind CSS v4** - 유틸리티 CSS
- **shadcn/ui** - 기존 `table`, `card`, `badge`, `button`, `skeleton` 재사용
- **Lucide React** - 아이콘

### 🗄️ 데이터 소스
- **Notion** (`@notionhq/client`, 신규 도입 제안) - 견적 데이터 입력·조회

### 📄 PDF
- **`@react-pdf/renderer`** (신규 도입 제안) - 서버에서 한글 폰트 임베딩 PDF 생성

### ✅ 테스트
- **Vitest 5** - 서비스/리포지토리 단위 테스트 (TDD)

### 📦 패키지 관리
- **npm**

> 신규 라이브러리 2종(`@notionhq/client`, `@react-pdf/renderer`)은 제안이며, 도입 전 사용자 확인이 필요하다.
